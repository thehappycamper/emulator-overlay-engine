# Ruleset Extensions

This directory is reserved for future challenge and session rulesets. A ruleset may define objectives, progress, completion, penalties, scoring, or outcomes; numeric points are optional.

Examples:

- Nuzlocke scoring.
- Low-score challenge rules.
- Per-Pokemon score tracking.
- Boss fight restrictions.
- Race completion and shared objectives.
- Cross-domain objective mappings.

Rulesets should be deterministic, documented, and backed by sample event fixtures when possible.

No ruleset runtime or public progress/result contract exists yet. See `docs/knowledge/product-vision.md` for the canonical future direction.
