# Security Policy

## Public Repository Safety

Do not commit:

- ROMs, BIOS files, or copyrighted game assets.
- Personal save files.
- Access tokens, API keys, SSH keys, cookies, or emulator account data.
- Local absolute paths that expose private machine details.
- Templates or fixtures generated from private play sessions unless they have been scrubbed.

## Reporting

For now, open a GitHub issue for non-sensitive security concerns. For sensitive issues, contact the repository owner privately once public repository contact details are available.
