# Example Ruleset Extension

This is a template for custom challenge scoring.

Rulesets should define event names, scoring values, and any projection rules needed by the overlay.

## Responsibilities

- Define scoring rules.
- Define event inputs.
- Keep calculations deterministic.
- Include example event fixtures.

## Not Responsible For

- Reading emulator memory.
- ROM-specific data extraction.
- Overlay layout beyond optional display metadata.
