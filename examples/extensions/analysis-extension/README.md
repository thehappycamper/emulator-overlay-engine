# Example Analysis Extension

This is a template for decision-support modules.

Use this for Battle Factory set matching, opponent move prediction, route recommendations, score projections, or other higher-level analysis.

## Responsibilities

- Consume normalized state and data extensions.
- Produce deterministic analysis outputs.
- Document assumptions and confidence scoring.
- Include fixtures for representative scenarios.

## Not Responsible For

- Reading emulator memory.
- Owning source data tables.
- Rendering UI directly.
