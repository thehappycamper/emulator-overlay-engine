# Example Transport Extension

This is a template for moving normalized state between an adapter and the overlay.

Use this for file polling, WebSockets, HTTP, named pipes, or emulator bridge protocols.

## Responsibilities

- Move normalized state payloads.
- Document connection/setup details.
- Keep transport concerns separate from Pokemon calculations.

## Not Responsible For

- Emulator memory reads.
- Game mapping.
- UI rendering.
- Damage, capture, or score calculations.
