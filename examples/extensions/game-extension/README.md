# Example Game Extension

This is a template for a generation, game, or ROM-hack mapping extension.

Use this when a game has specific memory addresses, struct layouts, ID mappings, mechanics, encounters, trainers, or facility data.

## Responsibilities

- Identify supported game, revision, or ROM-hack version.
- Map source IDs into normalized species, move, item, ability, and location IDs.
- Document mechanics differences from baseline generation behavior.
- Provide fixtures or tests where possible.

## Not Responsible For

- Connecting to an emulator.
- UI layout.
- Generic engine calculations unless the target changes mechanics.
