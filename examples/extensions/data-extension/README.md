# Example Data Extension

This is a template for static or extracted Pokemon data.

Use this for species, moves, items, abilities, learnsets, TM compatibility, encounters, trainer teams, Battle Factory sets, or ROM-hack data tables.

## Responsibilities

- Document data source and target version.
- Provide normalized IDs or ID mapping notes.
- Avoid copyrighted assets, ROMs, saves, and secrets.
- Include small synthetic fixtures when possible.

## Not Responsible For

- Emulator memory reads.
- Formula changes.
- Overlay layout.
