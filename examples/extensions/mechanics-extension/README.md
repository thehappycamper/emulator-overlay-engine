# Example Mechanics Extension

This is a template for generation or ROM-hack mechanics differences.

Use this when formulas or rules differ from the baseline engine assumptions.

## Responsibilities

- Document the mechanic difference.
- Expose deterministic rules or configuration.
- Include fixtures showing expected outputs.

## Examples

- Different damage formula.
- Physical/special split changes.
- Type chart changes.
- Critical hit changes.
- Weather, ability, or item behavior changes.
- Capture formula changes.
