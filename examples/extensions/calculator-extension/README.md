# Example Calculator Extension

This is a template for custom calculations.

Use this for calculations that are domain-specific or game-specific but should remain outside shared platform code.

## Examples

- Battle damage.
- Catch odds.
- Stat projection.
- Learnset availability.
- Type matchup scoring.
- Encounter probability.
- Custom game resource calculations.

## Responsibilities

- Declare required state fields and data dependencies.
- Produce deterministic outputs.
- Document formulas and assumptions.
- Include fixtures for expected results when possible.

## Not Responsible For

- Reading emulator memory.
- Owning raw data tables.
- Rendering UI directly.
