# Templates

Templates are user-facing bundles that assemble modules/extensions, mappings, calculated fields, fixtures, and UI panel preferences into a reusable overlay setup.

Community templates can live here once they are reviewed and safe to publish.

Template manifests should follow:

```text
src/schemas/template.schema.json
```

Examples live in:

```text
examples/templates/
```

Do not commit ROMs, BIOS files, copyrighted game assets, personal saves, secrets, or local absolute paths.
