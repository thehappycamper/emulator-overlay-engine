This directory is the human and agent knowledge base for Pokemon Overlay Engine.

- `decisions/` - architecture decision records.

## Documentation Policy

Documentation is part of the deliverable. Any change that affects behavior, architecture, public API, supported emulators, features, workflow, or project direction should update the relevant docs in the same commit.

Keep docs short enough to maintain. Prefer concrete status, file paths, and decisions over broad narrative.
