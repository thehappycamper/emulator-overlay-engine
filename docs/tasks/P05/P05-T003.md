## Objective

Turn the proven Emerald Rev 0 mGBA acquisition reader into a named/versioned, schema-validated source snapshot with a partial-write-safe local handoff. This task ends before mapping or normalized-state delivery.

## Why This Task Exists

`P05-T002` proved live memory acquisition but intentionally emitted only a developer diagnostic. The P05 pipeline needs a stable source-facing contract before declarative mapping can transform acquisition values into Pokemon domain state. ADR 0018 records the public contract and handoff decision.

## Acceptance Criteria

- The source contract has a stable ID/version and canonical adapter-owned schema.
- Current supported reader output creates a snapshot that validates against the contract.
- Missing, malformed, version-incompatible, and internally inconsistent snapshots fail deterministically.
- Unsupported ROM identity cannot create or publish a valid source snapshot.
- Snapshot replacement does not expose partial JSON at the canonical path.
- Source fixtures participate in repository schema validation.
- Full `npm test`, syntax, JSON, Markdown-link, and diff validation pass.

## Implementation Notes

Valid source snapshots contain contract metadata, exact game/revision identity, first-party source data, raw battle flags/first opponent, and raw map group/number/local coordinates. Diagnostic statuses remain text-buffer-only and clear the canonical handoff. The file path comes from `EMERALD_SOURCE_SNAPSHOT_PATH`, which must be present in mGBA's process environment before launch.

The source schema lives with the adapter because its fields describe one game/revision/acquisition layout. Platform mapping continues to treat the source descriptor as opaque. The Lua serializer cannot execute Ajv, so it builds a fixed contract shape after identity and party-count checks; automated tests validate its mirrored Node output and pin contract/write operations.

## Security/Compatibility Considerations

The provider remains read-only and exact-fingerprint gated. Valid files contain derived gameplay telemetry only. Temporary files are written beside the target and closed before replacement. Windows Lua replacement can create a brief missing-file window but cannot expose a partially written canonical file. The contract is new; future breaking shape changes require a new contract version. No shared platform schema embeds Pokemon or mGBA fields.
