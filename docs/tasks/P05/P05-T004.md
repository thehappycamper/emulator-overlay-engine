## Implementation Notes

The mapping owns one party slot and one opponent slot because those are the only source entries currently acquired. A zero party count maps to `[]`; an inactive battle omits `battle.opponent` because the current Pokemon schema does not accept `null` there.

Names, types, stats, moves, location name, bag, TMs, and encounters use explicit literals. Raw revision, CRC, party count, battle state/flags, and location coordinates are retained under `extensions["pokemon.emerald.us-rev0.mgba.acquisition"]` so no source information is silently lost or misrepresented as normalized meaning.

`tools/emerald-live-state.mjs` performs change-detected recursive polling. It validates and writes only after the previous cycle completes. Errors are logged once per distinct message and do not overwrite the last complete output.
