## Objective

Clarify that the platform core is source-agnostic — emulator memory is one gameplay data source among several possible source-provider types, not a platform-wide assumption — and update adapter-contract documentation accordingly. Preserve `Source Provider -> Source Contract -> Mapping -> Normalized State` as the acquisition-independent boundary.
