# P01-T005: Document Event-Driven Platform Vision

## Objective

Record the long-term product pipeline (`Source → Mapping → Normalized State → Event Detection → Normalized Events → Rules/Analysis/Subscriptions → Actions → Overlays/Automations/Sessions`) as canonical product vision, and record semantic events as a future platform primitive.

## Why This Task Exists

Backfilled from git history. Recorded in `docs/decisions/0013-semantic-events-as-platform-primitive.md` (extends ADR 0008) and `docs/knowledge/product-vision.md` (new canonical vision document).

## Dependencies

`P01-T004` (mapping foundation) — the vision explicitly builds on "the implemented foundation currently stops at normalized state," per `product-vision.md`.

## Non-Goals

Explicitly and repeatedly stated as not implemented by this task: event schema, event detector, event bus, subscription model, action schema, session protocol, transport, or persistence model. ADR 0013 states this directly: "This decision does not define an event schema, detector API, event bus, subscription model, action schema, session protocol, transport, or persistence model."

## Acceptance Criteria

Vision document is internally consistent with `AGENTS.md`'s architecture rules and does not imply any event/action/session functionality exists yet. Verified during a later adversarial review (see `P01-T004`'s Review Findings) that nothing in the actually-implemented mapping contract (`P01-T004`) would force a breaking redesign to reach this vision — the one identified touch point (adding a `previous`-state root to the expression evaluator for diff-based event detection) is additive, not breaking.
