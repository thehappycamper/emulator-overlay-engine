# Commercial Model

The repository uses the MIT License.

Users can use, modify, share, and commercially use the open source project under the license terms.

## Intended Free/Open Parts

- Core platform code.
- Pokemon first-domain MVP.
- Public schemas.
- Public examples.
- Community extensions and templates accepted into the repository.

## Possible Future Paid Offerings

- Hosted template sharing.
- Account sync.
- Premium template packs.
- Marketplace for reviewed premium templates.
- Managed setup help.
- Support and consulting.
- Sponsored feature development.

## Marketplace Notes

Marketplace support is not implemented.

Before adding marketplace behavior, define:

- Template licensing rules.
- Revenue split.
- Review requirements.
- Safety and copyright policy.
- Versioning and compatibility guarantees.
- Whether paid templates can depend on open community extensions.
